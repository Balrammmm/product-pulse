# ProductPulse

AI-powered review intelligence for product decisions. Upload customer-review CSVs to explore sentiment, recurring pain points, feature requests and roadmap recommendations.

[Open the demo](https://product-pulse-xi.vercel.app) · [Application source and full documentation](./product-pulse/README.md)

## Run locally

```sh
cd product-pulse
npm install
npm run dev
```

AI-provider credentials belong in a local environment file and stay server-side. A local analysis fallback keeps the demo usable without provider credentials. See the application README for setup and limitations.
